# Terminal Quiz Game
this is a script that give a  simulation of an examination MCQs test

## problem statement

Many small school in Cameroon manage in storing students academic scores manually and in order , leading to inadequete storage of student performance affecting it performance

## 🎯 Project Goals

- Allow user to see day to day performance .
- facilited storage  information.
- facilate information organization

## 🛠 Tech Stack

**LANGUAGE**
- Bash

**OTHER TOOLS**
- GitHub

## 🖥 Features

- Ask and store information related to the project
- provide question and answer to the user
- reject invalide answer not provided by the question
- Display  information (score date and name) in a file
- arrange  in descending order the top 5 best score
